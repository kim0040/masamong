# 내부 변경 이력

이 파일은 릴리스 단위의 주요 변경을 Git과 함께 추적하는 내부 기록입니다. 사용자에게
보이는 현재 기능은 [문서 허브](../README.md)와 기능 기준 문서를 우선합니다. 작업 중간
메모나 계획은 이력에 섞지 않고, 재현 가능한 판단 근거만 남깁니다.

형식은 [Keep a Changelog](https://keepachangelog.com/ko/1.0.0/)를 참고하며, 버전 번호는
[Semantic Versioning](https://semver.org/lang/ko/)을 따릅니다.

- 의미 라우팅, 선택적 기억 회수, 동일 호출 내 컨텍스트 digest로 구성한 대화 하네스
- 학교 공지 자연어 등록·확인·초기 수집·05시 순차 수집·사용자별 09시 기본 알림
- 20개 대학 편입 공지 DM 구독과 공식 원문 링크
- 기능별 개인정보 동의 버튼, 철회 이력, DM 전용 개인 기능
- 기상청 지진 1분 감시와 연속 사건 메시지 수정, 특보·태풍·예보 확장
- CometAPI Gemini native 이미지 생성과 대화 기억 기반 프롬프트
- 전역/기능/서버/사용자/DM별 LLM·이미지·웹 검색 사용량 예약과 circuit breaker

### 변경

- 운영 RAG를 스코프가 분리된 의미 임베딩 및 TiDB 벡터 검색으로 정리
- 저사양 운영 프로필에서 BM25/FTS5 생성·검색·자동 재구축을 명시적으로 금지
- 최근 원문, 관련성 gate, 최대 기억 블록으로 불필요한 기억 주입을 차단
- 최신·금융·지역 사실 질문은 성공한 외부 근거가 없으면 답을 만들지 않도록 변경
- Discord 메뉴를 기능 그룹으로 정리하고 개인 메뉴와 공개 출력 경계를 분리
- 편입 지원 대학의 공식 공지 링크를 특정 대학 전용 버튼 없이 하나의 동일한 선택
  메뉴로 제공하고, 자동 접근 불가 출처는 직접 확인으로 명확히 구분
- 학교·편입·운세 알림의 재시작 중복 전송 방지와 실패 항목의 제한적 재시도 강화

### 수정

- 단일 TiDB 연결에서 서로 다른 비동기 작업의 쓰기가 한 commit/rollback에 섞일 수
  있던 트랜잭션 경계
- Discord 버튼 acknowledgement 지연, 이미지 중복 생성, 출처 반응 토글 동작
- 서버 페르소나가 다른 서버 또는 공통 재난 알림에 섞일 수 있던 스코프 경계
- KRX TLS/API 키 경로, yfinance 무제한 대기, 취소된 도구 호출의 회로 상태 누수
- 실패한 검색 문자열이 성공 근거처럼 최종 답변에 전달되던 경로
- 웹검색·날씨 등 도구가 정상 종료되어도 성공·빈 결과·실패를 구분할 수 없던 운영 로그
- AI 요청 종료·단계·전체/LLM/도구 소요 시간이 없어 느린 구간과 중단 지점을 찾기
  어려웠던 운영 로그
- 1분 지진 정상 조회가 매번 INFO로 쌓여 중요한 오류와 요청 흐름을 가리던 로그 노이즈
- 장시간 실행 중 cooldown·emoji 캐시가 무제한 커질 수 있던 경로
- 비용 발생 smoke 스크립트가 도움말이나 무인 실행만으로 provider를 호출하던 경로

### 검증

- 오프라인 기능·회귀 테스트, 명령어 표면 검사, 문법 컴파일, 추적 파일 비밀값 검사
- 운영 DB를 삭제·수정하지 않는 stale-read 상태/용량/기억 품질 감사
- 실제 Discord 의미 라우팅 smoke와 배포 후 systemd·timer·오류 로그 검증

## 버전 관리 규칙

### 버전 번호: MAJOR.MINOR.PATCH

- **MAJOR**: 호환되지 않는 API 변경
- **MINOR**: 하위 호환되는 기능 추가
- **PATCH**: 하위 호환되는 버그 수정

### 변경 유형

- `Added`: 새로운 기능
- `Changed`: 기존 기능의 변경
- `Deprecated`: 곧 제거될 기능
- `Removed`: 제거된 기능
- `Fixed`: 버그 수정
- `Security`: 보안 관련 수정
- `Optimized`: 성능 최적화
