# 내부 유지보수 기록

이 디렉터리는 마사몽을 유지보수할 때 필요한 측정, 판단 근거, 이행 원칙과 변경 이력을
Git으로 보존하는 공간입니다. 사용자용 README나 기능 안내에서는 이 문서를 제품 사용법의
근거로 직접 연결하지 않습니다.

## 포함하는 문서

| 문서 | 용도 |
| --- | --- |
| [CHANGELOG.md](CHANGELOG.md) | 릴리스 단위의 주요 변경을 간략히 추적합니다. |
| [RAG_ANALYSIS.ko.md](RAG_ANALYSIS.ko.md) | 특정 시점의 기억 회수 측정과 원인 분석을 보존합니다. |
| [RAG_IMPROVEMENT_PLAN.ko.md](RAG_IMPROVEMENT_PLAN.ko.md) | 분석에 따른 조치와 남은 판단 사항을 보존합니다. |
| [MEMORY_INDEX_MIGRATION.ko.md](MEMORY_INDEX_MIGRATION.ko.md) | 누적 기억을 삭제하지 않는 인덱스 이행 조건을 보존합니다. |

## 작성 기준

- 날짜, 대상 릴리스 또는 측정 조건을 첫머리에 적습니다.
- 관찰 사실, 결정, 아직 하지 않은 일을 구분합니다.
- 현재 코드와 다른 과거 상태는 과거 기록임을 분명히 표시합니다.
- 실제 사용자 데이터, 비밀값, 운영 서버 주소, 보호된 파일 경로는 기록하지 않습니다.
- 운영 절차가 확정되면 [운영·배포 가이드](../DEPLOYMENT.md) 또는 기능 기준 문서에
  반영하고, 여기에는 그 판단 근거만 남깁니다.
