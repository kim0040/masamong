## 내부 기록

`internal/`은 사용자 안내가 아니라 유지보수 근거를 남기는 Git 추적 영역입니다. 측정값과
결정 당시의 제약을 보존하되, 현재 제품의 사용법이나 배포 절차를 설명하는 기준 문서로는
사용하지 않습니다. 이 문서 허브와 루트 README에는 해당 기록을 나열하지 않으며,
유지보수자는 저장소의 `docs/internal/`에서만 관리합니다.

## 문서 갱신 원칙

- 사용자에게 보이는 기능이 바뀌면 사용자 가이드와 해당 기능 문서를 함께 갱신합니다.
- 설정·배포·데이터 계약이 바뀌면 코드와 같은 변경에서 운영 문서를 갱신합니다.
- 계획, 실험 수치, 일회성 조사 결과, 릴리스 작업 메모는 `internal/`에 남깁니다.
- 사용자 안내는 "무엇을 할 수 있는지"와 "어떻게 확인하는지"를 중심으로 친근한
  해요체로 작성합니다. 운영·설계 문서는 검증 가능한 사실과 조건을 명확히 적습니다.
- 토큰, API 키, 실제 Discord ID, DB 접속 정보, 개인 대화·프로필 원문은 어떤 문서에도
  기록하지 않습니다.
